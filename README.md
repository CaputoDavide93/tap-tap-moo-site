## ✨ Features

## 🚀 Quick Start

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

GitHub Pages publishes the `main` branch root. The privacy page must stay true to the app's own `docs/privacy.md`; change both together.
