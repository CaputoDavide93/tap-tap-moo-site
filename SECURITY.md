# 🔒 Security

This repository is a static website: HTML and CSS, with no scripts, forms, cookies or server code.

To report a problem with the site or with the Tap Tap Moo app, open a [private security advisory](https://github.com/CaputoDavide93/tap-tap-moo-site/security/advisories/new) on this repository. Please don't open a public issue for a security problem.
