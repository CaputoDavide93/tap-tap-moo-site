# ❓ FAQ

## What is this repository?

It is the public website for the Tap Tap Moo app: a home page, the privacy policy, a contact and support page and a philosophy page, each in every language the app ships. GitHub Pages serves it.

## Does the site use cookies, analytics or scripts?

No. The pages are static HTML and CSS, and `make check` fails if a script, form or iframe appears. GitHub Pages hosts the site and may keep standard server logs, which the privacy policy says.

## Where is the privacy policy?

At <https://caputodavide93.github.io/tap-tap-moo-site/privacy/>, and in each other language at `/<code>/privacy/`, for example `/it/privacy/`. The app's Settings and the store listings link to it.

## Which languages does the site have?

English, Italian, Spanish, French, German, Brazilian Portuguese, Dutch and Polish. Each page has a language row linking the same page in all of them.

## Can I use the pages for my own app?

The code is MIT licensed, so the layout and styles are free to reuse. The text is the Tap Tap Moo policy and describes that app only; write your own statements and have them checked against your own app.

## Does the site say the app is approved or good for child development?

No. It describes what the app keeps and does not make approval or development claims.

## How do I report a problem with a page?

Open an issue with the page address, your browser and operating system, and a screenshot for layout problems. [CONTRIBUTING.md](../CONTRIBUTING.md) lists what to include. A security problem goes through a private advisory, as [SECURITY.md](../SECURITY.md) explains.

## Why is the support address not in the README?

The README and docs do not repeat it so the address lives in one place, on the contact and privacy pages, where the app and the stores point.
